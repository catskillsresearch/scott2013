# Source materials

`ScottPROGIC2013.pdf` is Dana S. Scott, *Stochastic λ-calculi: An extended
abstract*, Journal of Applied Logic 12 (2014), 369–376, circulated as the
PROGIC 2013 extended abstract. It is included for citation and transcription
checking only. It is **not** licensed under this repository's Apache-2.0
terms.

Please cite the journal version:

> Dana S. Scott. Stochastic λ-calculi: An extended abstract. *Journal of
> Applied Logic* 12 (2014), 369–376.

## Working transcription

The PDF is born-digital (Apple Pages / Quartz, 7 pages, embedded fonts).
The working Markdown copy is `ScottPROGIC2013.md`, extracted from the PDF
text layer with `pdftotext` and lightly cleaned (Pages soft-return `!`
characters removed; superscripts such as $2^n$ restored from the page
layout). Vision OCR is not used.

Scott's wording remains under Scott's / the publisher's copyright. Do not
treat the PDF or transcription as redistributable under Apache-2.0.
